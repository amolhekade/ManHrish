# ManHrish Technologies — Website

A responsive, static HTML/CSS/JavaScript website for ManHrish Technologies.

## Included
- `index.html` — complete landing page
- `styles.css` — responsive styles and layout
- `script.js` — mobile navigation and dynamic copyright year
- `assets/` — custom SVG logo, favicon, and interface icons

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

No build tools, framework, database, or server are required.

## Deploy for free

### Netlify (easy option)
1. Extract the ZIP file on your computer.
2. Sign in to Netlify.
3. Choose **Add new site** → **Deploy manually** (wording may vary).
4. Drag the extracted project folder into the deployment area.
5. Netlify will provide a public URL.

### GitHub Pages
1. Create a GitHub repository and upload the contents of this folder to the repository root.
2. In repository Settings, open Pages.
3. Choose deployment from the `main` branch and `/ (root)`.
4. Save and wait for the published URL.

### Any web server / IIS
Copy `index.html`, `styles.css`, `script.js`, and the `assets` folder to the website's document root. The site uses relative paths and can be hosted as a static site.

## Before going live
- Replace `hello@manhrish.com` in `index.html` if you choose another contact address.
- Add your actual phone number, address, legal company name, and social links when ready.
- Confirm that your domain is registered and configure its DNS at your hosting provider.
- Google Fonts are loaded from Google Fonts; if offline operation is required, use local font files or remove the font imports.
- The contact CTA opens the visitor's email application. It is not a backend form and does not store submissions.
- Review all wording and legal claims before publishing.
